# BaristaWeb — Portfolio

موقع البورتفوليو الشخصي لعبد الرحمن الحوراني.

## الرفع على GitHub Pages
1. أنشئ مستودع جديد على GitHub باسم `BaristaWeb` (Public).
2. ارفع **محتويات** هذا المجلد كما هي إلى جذر المستودع:
   `index.html`، `favicon.svg`، `.nojekyll`، ومجلد `assets/`.
3. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقة أو دقيقتين يصير الموقع على:
   `https://<اسم-حسابك>.github.io/BaristaWeb/`

> إذا اسم الحساب أو المستودع مختلف، عدّل رابط `og:image` في `index.html` (يُستخدم لصورة المعاينة عند مشاركة الرابط).
